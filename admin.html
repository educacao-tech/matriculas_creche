Exportar e Publicar Alterações

As alterações já estão ativas neste navegador. Para disponibilizá-las para todos os cidadãos no GitHub Pages:

  1. Clique em "Baixar config.js" abaixo;
  2. Substitua o arquivo config.js na pasta do seu repositório;
  3. Faça o git commit e git push no GitHub.

Conexão Direta com GitHub

Conecte um Personal Access Token (PAT) do GitHub para que qualquer alteração feita no painel seja comitada e publicada automaticamente no repositório oficial.

O token é salvo de forma segura no armazenamento local do seu navegador e nunca é compartilhado publicamente.
Como obter seu token no GitHub:
  1. Acesse Gerar Token no GitHub ;
  2. Marque o escopo repo (ou permissão Contents: Read and write em Fine-grained tokens);
  3. Clique no final da página em Generate token;
  4. Copie o código gerado (começa com ghp_) e cole no campo acima.
